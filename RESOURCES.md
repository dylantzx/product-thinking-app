# Product Thinking Resources

## Knowledge

- [IDG: Product Thinking pathway (overview)](https://www.idg.gov.sg/product-thinking/)
  Seven-module course from Singapore's Institute of Digital Government. Use for: the overall map and learning objectives.
- [IDG module 1: Understanding the Problem](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking1/)
  Problems before solutions, three principles. Use for: lesson 1.
- [IDG module 2: Start With The Whys](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking2/)
  Five Whys and choosing a root cause. Use for: root-cause lessons.
- [IDG module 3: Craft a Clear Problem Statement](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking3/)
  The 4Cs framework (Clarity, Consequence, Cause, Confirmation). Use for: problem statements.
- [IDG module 4: Metrics](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking4/)
  SMART, leading/lagging indicators, Value-Cost Ratio. Use for: metrics lessons.
- [IDG module 5: Assumptions and Risks](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking5/)
  Market, technical, team risk; four de-risking stages. Use for: de-risking lessons.
- [IDG module 6: A Good Customer Experience](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking6/)
  11-star framework. Use for: experience design.
- [IDG module 7: Key Takeaways](https://www.idg.gov.sg/guides-resources/ai-301-build-with-ai/productthinking7/)
  Summary of toolkit and three mindset shifts. Use for: revision.
