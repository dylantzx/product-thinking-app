# Product Thinking

Learn to build an app that solves a real problem, and to tell whether it worked. Based on the Institute of Digital Government (IDG) Product Thinking course.

## Start here: play Product Brawl

**[▶ Play Product Brawl](https://dylantzx.github.io/product-thinking-app/games/product-brawl.html)** (about 15 minutes, best with a keyboard)

Don't like reading long documents? You don't have to. Product Brawl teaches the whole course as a typing fighting game:

1. **Read** a short question with two possible answers.
2. **Type** the answer you believe, exactly as shown.
3. **Strike.** Faster, cleaner typing lands a bigger hit. Type the wrong answer and you take the hit.

After every answer the game explains *why* in one or two lines, so you learn as you play. Questions you get wrong come back until you land them, and the ending lists what you missed.

There is one opponent per lesson, each a bad habit to knock out:

| Round | Opponent | The habit you beat | What you learn |
|---|---|---|---|
| 1 | Solution Sam | Builds first, asks what the problem was later | Problems before solutions |
| 2 | Vague Vera | "Things are bad, kind of, for some people, maybe" | Writing a 4Cs problem statement |
| 3 | Vanity Vic | Numbers go up, nothing gets better | Metrics that measure the outcome |
| 4 | Big Bang Bo | One giant launch, no tests | De-risking by building in stages |
| 5 | Clunky Carl | "Please read the 40-page manual before use" | A good customer experience |
| 6 | The Status Quo | "We have always done it this way" | Putting the toolkit together |

Before each round, the VS screen shows that lesson's key ideas in a few bullets. Forgot something mid-fight? Press **Esc** or **MENU** to pause and see the notes again. You can design your own fighter before you start.

## Run it yourself

Everything is plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or visit the live site at **https://dylantzx.github.io/product-thinking-app/**.

| Path | What's there |
|---|---|
| `games/product-brawl.html` | The game, all in one file |
| `lessons/` | The six lessons |
| `reference/` | Toolkit cheat sheet and glossary |
| `assets/` | Shared styles and the quiz and notes scripts |
